# GA-HRMS

A modern, scalable Human Resource Management System (HRMS) dashboard and management platform built with React, Vite, Tailwind CSS, TypeScript, and Radix UI.

## Features

- **Executive & Operational Dashboard**: Real-time KPI metrics, attendance tracking, department distribution, and upcoming activities.
- **Employee Directory & Profiles**: Comprehensive workforce management with role-based attributes and department organization.
- **Attendance & Leave Management**: Request workflows, approval pipelines, leave balances, and check-in/out logs.
- **Recruitment & Applicant Tracking**: Job postings, hiring pipelines, candidate stages, and interview schedules.
- **Payroll & Compensation**: Salary breakdowns, payslips, benefits, and payout statuses.
- **Performance & Reviews**: Goal setting, OKRs, appraisal cycles, and feedback logs.
- **Settings & Role Management**: Organization-level settings, permission matrices, and system configurations.

## Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Component Primitives**: [Radix UI](https://www.radix-ui.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts & Visualizations**: [Recharts](https://recharts.org/)
- **Routing**: [React Router v6](https://reactrouter.com/)

## Getting Started

### Prerequisites

- Node.js (v18.0 or higher)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Techwolf78/ga-hrms.git
   cd ga-hrms
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
